第〇章：Qt 是什么？
================================================================================

  Qt 是一个 C++ 的 GUI 框架（GUI = 图形用户界面，就是你眼睛看到的东西）。
  它本质上就是一个"积木箱"——里面有很多现成的积木（按钮、下拉框、标签、
  文本框、滚动区域...），你只需要告诉它们怎么排列、怎么互相连接就行了。

  你的项目用的是 Qt6，编译器是 MinGW（Windows 上的 GCC）。


================================================================================
第一章：从 main.cpp 开始 —— 程序怎么启动的？
================================================================================

  看 src/main.cpp（只有 40 行）：

  ┌──────────────────────────────────────────────────────────────┐
  │ int main(int argc, char *argv[]) {                           │
  │     QApplication app(argc, argv);    // ① 创建一个"程序壳"  │
  │     app.setStyleSheet("...");        // ② 设定全局样式      │
  │     MainWindow w;                    // ③ 创建主窗口         │
  │     w.show();                        // ④ 显示主窗口         │
  │     return app.exec();               // ⑤ 进入事件循环       │
  │ }                                                             │
  └──────────────────────────────────────────────────────────────┘

  关键概念：事件循环
  "事件循环"就是一个永不停机的 while(true) 循环，随时监听：
  - 鼠标点了哪里？
  - 键盘按了什么？
  - 窗口变大了吗？
  一旦有"事件"发生，Qt 就通知对应的部件去处理。

  这就是为什么你的程序不会一闪而过——app.exec() 在里头死循环等着你操作。

第二章：积木怎么搭的？—— 布局系统 (Layout)
================================================================================

  Qt 不用"像素坐标"摆积木（那样换个屏幕就乱了），而是用"布局"。

  你项目里用的四种布局（类比表格排版）：

  ┌──────────────────────────────────────────────────────────────┐
  │ QVBoxLayout    垂直排列，从上到下                            │
  │   [按钮A]                                                    │
  │   [按钮B]      ← 一个在另一个下面                            │
  │   [按钮C]                                                    │
  ├──────────────────────────────────────────────────────────────┤
  │ QHBoxLayout    水平排列，从左到右                            │
  │   [按钮A] [按钮B] [按钮C]  ← 排成一排                        │
  ├──────────────────────────────────────────────────────────────┤
  │ QGridLayout    网格排列（类似 Excel）                         │
  │   [0,0] [0,1] [0,2]                                          │
  │   [1,0] [1,1] [1,2]                                          │
  │   [2,0] [2,1] [2,2]                                          │
  ├──────────────────────────────────────────────────────────────┤
  │ QStackedWidget 叠加页（像翻书）                               │
  │   每次只显示一页，其他页藏在后面                               │
  │   你的四个标签页就是用这个实现的                               │
  └──────────────────────────────────────────────────────────────┘

  实际例子（mainwindow.cpp 第 193-213 行）：

  QWidget* central = new QWidget();           // 一个空白容器
  QVBoxLayout* mainLayout = new QVBoxLayout(central);  // 垂直排列

  mainLayout->addWidget(顶栏);                // 顶栏
  mainLayout->addWidget(QStackedWidget);      // 四页正文（中间撑满）
  mainLayout->addWidget(底栏);                // 底栏

  结果就是：
  ┌──────────┐
  │  顶栏     │  ← QHBoxLayout 水平排
  ├──────────┤
  │          │
  │  正文     │  ← QStackedWidget（四页之一）
  │          │
  ├──────────┤
  │  底栏     │  ← QHBoxLayout 水平排四个按钮
  └──────────┘

第三章：怎么让按钮"干某事"？—— 信号与槽 (Signal & Slot)
================================================================================

  这是 Qt 最重要的机制。"信号"就是"发生了一件事"，"槽"就是"这件事的后
  续动作"。

  比喻：按门铃 → 有人开门
  - 信号 = 门铃被按下
  - 槽   = 去开门

  代码长这样：
  connect(按钮,  &QPushButton::clicked,    // 信号：按钮被点击
          this,  &MainWindow::onPlanRoute);  // 槽：执行 onPlanRoute 函数

  常见信号：
  - clicked()           按钮被点击
  - currentIndexChanged 下拉框选项变了
  - textChanged         文本框内容变了

  你项目里每颗按钮、每个下拉框后面都连着一条 connect，
  这就是为什么一点"规划路径"就能跑 Dijkstra——本质是 clicked 信号触发了
  onPlanRoute() 槽函数。

第四章：各种积木介绍
================================================================================

1. QPushButton（按钮）
   最常用的积木。风格用 setStyleSheet() 控制：

   QPushButton* btn = new QPushButton("✨ 规划最短路径 ✨");
   btn->setStyleSheet(
       "QPushButton {"
       "  background: #1f6d49;"       // 背景墨绿
       "  color: white;"              // 文字白色
       "  border-radius: 30px;"       // 圆角
       "  padding: 14px 24px;"        // 内间距
       "}"
       "QPushButton:hover { background: #0e5437; }"  // 鼠标悬停变深
   );
   connect(btn, &QPushButton::clicked, this, &MainWindow::onPlanRoute);

2. QComboBox（下拉框）
   用户从一组选项中选一个。你的起点/终点/策略选择器全都是它。

   combo->addItem("最短距离");    // 添加选项
   combo->addItem("最短时间");
   combo->addItem("自行车道");
   // 选中的选项变化 → 触发槽
   connect(combo, &QComboBox::currentIndexChanged, ...);

3. QLabel（文本标签）
   显示一段文字。支持 HTML 富文本（你的排行榜条目就是 HTML 表格渲染的）：

   QLabel* label = new QLabel();
   label->setText("<b>加粗</b> <span style='color:red'>红色</span>");
   label->setTextFormat(Qt::RichText);  // 告诉它这是 HTML

4. QLineEdit（单行输入框）
   搜索框、日记标题输入框。

5. QTextEdit（多行文本框）
   日记正文就是用它写的。

6. QScrollArea（可滚动区域）
   把一个可能超长的大内容包起来，加滚动条。
   你的推荐页、查询页、日记页都在 QScrollArea 里面。

7. QGraphicsView（画图组件）
   这就是你的地图！MapWidget 继承自 QGraphicsView。

8. QStackedWidget（翻页器）
   每次只显示一页。你的四个标签页切换就是用这个：
   m_stack->setCurrentIndex(0);  // 显示第0页（导航）
   m_stack->setCurrentIndex(1);  // 显示第1页（推荐）

第五章：样式表 (StyleSheet) —— 怎么让界面好看？
================================================================================

  Qt 的样式表语法跟 CSS 几乎一模一样。你项目里的每个部件都有大量
  setStyleSheet() 调用。

  格式：
  "部件类型 { 属性: 值; 属性: 值; }"
  "部件类型:状态 { 属性: 值; }"

  常用属性：
  background / color      背景色 / 文字色
  border / border-radius  边框 / 圆角
  padding / margin        内间距 / 外间距
  font-size / font-weight 字号 / 粗细

  你项目里的颜色主题：
  #0a2b3e  = 深蓝（顶栏背景）
  #1f6d49  = 墨绿（主按钮）
  #f59e0b  = 琥珀金（美食/评分颜色）
  #0f5b7a  = 藏蓝（二级按钮）
  #d9e2ec  = 浅蓝灰（页面背景）

第六章：地图是怎么画出来的？
================================================================================

  MapWidget 继承自 QGraphicsView（Qt 的画布组件），src/mapwidget.cpp。

  画地图的四个层次（从下到上）：

  第1层：地图底图（图片）
  QGraphicsPixmapItem* m_mapItem = scene->addPixmap(北邮校园地图.jpg);

  第2层：蓝色路径线（导航结果）
  for (路径的每一段) {
      QGraphicsLineItem* line = scene->addLine(
          x1, y1, x2, y2,       // 起点终点坐标（像素）
          QPen(蓝色, 3px)        // 画笔
      );
  }

  第3层：红点标注（所有地标）
  for (每个地标节点) {
      scene->addEllipse(
          节点.pixelX - 6, 节点.pixelY - 6,  // 左上角
          12, 12,                              // 宽高
          QPen(边框色), QBrush(填充色)          // 不同设施类型不同颜色
      );
  }

  第4层：金色高亮（查询结果标注）
  scene->addEllipse(
      中心px-15, 中心py-15, 30, 30,
      QPen(金色, 3px), Qt::transparent  // 空心圆环
  );

  关键概念：Z值
  每个元素有一个 z 值，z 越大越靠前。
  底图 z=0 < 路径线 z=1 < 红点 z=2 < 高亮和起终点标记 z=3

第七章：事件过滤器 —— 怎么拦截滚轮？
================================================================================

  Qt 所有事件（鼠标/键盘/滚轮）从顶层的 QApplication 向下分发。
  你可以半路截住：

  qApp->installEventFilter(this);  // 告诉 Qt："所有事件先让我看看"

  bool eventFilter(QObject* obj, QEvent* event) {
      // 是滚轮事件吗？目标是下拉框吗？
      if (event->type() == QEvent::Wheel &&
          qobject_cast<QComboBox*>(obj))
          return true;  // 吞掉！下拉框收不到这个滚轮事件了
      ...
  }

  就这 5 行代码，所有下拉框的滚轮都失效了。
